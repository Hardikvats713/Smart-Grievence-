# START HERE — Smart Grievance

This is the populated project preparation pack. Read this file before asking an AI coding agent to implement anything.

## Before opening Antigravity
1. Extract this folder and open `SMART-GRIEVANCE-READY` as the project root.
2. Add the approved Smart Grievance logo files to `design/brand/`.
3. Add the approved home-screen mockup and other approved screen references to `design/references/`.
4. Add licensed Poppins font files to `mobile/assets/fonts/` when you have them. Do not download unlicensed font files.
5. Confirm the open decisions in `docs/11_DECISIONS_AND_OPEN_QUESTIONS.md`.
6. Read `AGENTS.md` and `docs/02_DESIGN_SYSTEM.md`.

## First Antigravity task
Give Antigravity the instruction in `docs/12_FIRST_TASK_FOR_ANTIGRAVITY.md`.

It must inspect the repository first, then implement only the reusable Flutter design foundation. Do not ask it to build all screens or backend services in one pass.

## What is intentionally not included
This pack is documentation and a project scaffold. It is not yet a runnable Flutter, NestJS or AI application. Generate framework scaffolds only after inspecting the machine and existing files.

## Keep these files updated
- `AGENTS.md`: standing coding-agent rules.
- `docs/11_DECISIONS_AND_OPEN_QUESTIONS.md`: decisions approved by the project owner.
- `docs/09_WORK_PLAN.md`: milestone progress.
- `docs/02_DESIGN_SYSTEM.md`: approved design system (change only with explicit approval).
